# Roadmap

Planned parts for both series, mapped to CompTIA's objective numbers. Titles are working titles.

## Core 1 (220-1201): Inside the Machine

Five domains: Mobile Devices 13%, Networking 23%, Hardware 25%, Virtualization and Cloud 11%, Hardware and
Network Troubleshooting 28%.

The parts don't follow CompTIA's numbering. They follow the order the ideas depend on each other: the motherboard
first, because everything plugs into it, and troubleshooting last, because it uses everything else. Objective
numbers appear on screen in every part, so people revising by objective can still find what they need.
