## Devices

| Question | Answer |
|---|---|
| Router vs switch | Router joins networks. Switch connects devices inside one network |
| Managed vs unmanaged switch | Managed = configurable (VLANs). Unmanaged = plug and play |
| Cable modem connects over | Coaxial cable (cable TV network) |
| DSL connects over | Telephone line (RJ11) |
| ONT stands for and does | Optical Network Terminal. Turns fiber light into Ethernet |
| MAC address size and format | 48 bits, 12 hex characters. First half maker, second half unique |
| What does a switch use to forward data? | MAC addresses |

## PoE

| Standard | Power |
|---|---|
| 802.3af (PoE) | up to 15.4 W |
| 802.3at (PoE+) | up to 30 W |
| 802.3bt Type 3 | up to 60 W |
| 802.3bt Type 4 | up to 90 W |

| Question | Answer |
|---|---|
| Two ways to supply PoE | PoE switch, or PoE injector |

## Connections and network types

| Question | Answer |
|---|---|
| Fastest usual home connection | Fiber |
| Which connection has high latency? | Satellite |
| Which connection depends on a clear line of sight to a tower? | WISP |
| Cable internet is shared with | Neighbors |
| DSL speed depends on | Distance from the provider's equipment |
| PAN | Personal Area Network, a few meters |
| LAN / WLAN | Local Area Network / Wireless LAN |
| MAN | Metropolitan Area Network, a city |
| WAN | Wide Area Network, the internet is one |
| SAN | Storage Area Network, servers to storage |

## Tools

| Tool | Job |
|---|---|
| Crimper | Attach an RJ45 plug |
| Cable stripper | Remove the outer jacket |
| Punchdown tool | Seat wires in a punchdown block or patch panel |
| Toner probe | Find a cable by tone |
| Cable tester | Check each wire |
| Loopback plug | Test a port |
| Network tap | Copy traffic for inspection |
| Wi-Fi analyzer | Channels and signal strength |
