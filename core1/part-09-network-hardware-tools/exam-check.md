# Exam check: Network Hardware, Connection Types and Tools

Cover the answers and try each one out loud first.

**1.** A wireless access point is mounted high on a ceiling, with a network cable nearby but no power socket. What lets it run from the network cable?
<details><summary>Answer</summary>Power over Ethernet (PoE), from a PoE switch or a PoE injector.</details>

**2.** A wiring cupboard holds dozens of unlabelled cables, and you must find which one goes to the reception desk. Which tool do you use?
<details><summary>Answer</summary>A toner probe, with a tone generator at the other end.</details>

**3.** A home has a fiber internet line that ends at a small box on the wall. What is the box?
<details><summary>Answer</summary>An optical network terminal (ONT). It turns the light signal into Ethernet.</details>

## More practice (written for this kit)

**4.** Which PoE standard delivers up to 30 watts?
<details><summary>Answer</summary>802.3at (PoE+).</details>

**5.** Which tool presses an RJ45 plug onto a cable?
<details><summary>Answer</summary>A crimper.</details>

**6.** Which tool seats wires into a patch panel and trims the extra?
<details><summary>Answer</summary>A punchdown tool.</details>

**7.** Which internet connection type has high latency because the signal travels so far?
<details><summary>Answer</summary>Satellite.</details>

**8.** Which network type covers a city?
<details><summary>Answer</summary>A MAN, Metropolitan Area Network.</details>

**9.** A technician wants to inspect traffic on a link without interrupting it. Which tool?
<details><summary>Answer</summary>A network tap.</details>

**10.** Which switch type lets you configure VLANs?
<details><summary>Answer</summary>A managed switch.</details>
