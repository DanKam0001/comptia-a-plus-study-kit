# Memorise list: Troubleshooting Displays, Mobile Devices and Printers (Core 1, Part 14)

Understand the video first, then learn these cold. They're the symptom-to-answer pairs a scenario question assumes you know.

## Displays and projectors

| Question | Answer |
|---|---|
| Black screen or "No signal": check first | The input source, then the cable |
| Fuzzy, stretched or distorted image: fix | Set the native resolution |
| Dead pixel: can it be fixed? | Usually not. Replace the screen if there are many |
| Burn-in affects mostly | OLED screens (a static image left too long) |
| Projector shuts off, then works after resting | Overheating. Clean the filters and vents |
| Projector gives no picture, lamp-hours counter is high | Burnt-out bulb. Replace the lamp (let it cool first) |
| LCD very dim, picture is faintly visible | Failing backlight or inverter |
| No sound over a video cable | VGA and DVI carry no audio. Use HDMI or DisplayPort, or check the output device |
| Wrong colors on a VGA screen | Loose cable or bent pins |

## Mobile devices

| Question | Answer |
|---|---|
| Swollen battery: what do you do? | Stop using it, do not charge it, do not puncture it, replace it safely and recycle it. Fire risk |
| Touch does not respond but the picture is fine | Digitizer fault |
| Touches land in the wrong place | Restart, remove the screen protector, recalibrate touch |
| Phone gets wet | Power off, do not charge, repair |
| Slow charging or not charging | Try another cable and charger, clean or repair the port |
| Cannot install new apps | No free storage, or an outdated OS |
| Pop-ups, heat, fast battery drain, unknown apps | Malware. Remove the apps, scan |
| No connectivity: first checks | Airplane mode, toggle Wi-Fi or Bluetooth, reset network settings |
| Stylus stops working | Charge or replace its battery, re-pair, replace the tip |

## Printers

| Question | Answer |
|---|---|
| Line down every laser page | Dirty or damaged drum or toner cartridge |
| Line down inkjet pages | Clogged print head. Run the cleaning cycle |
| Echo or ghost images | Worn drum or the fuser |
| Speckling | Stray toner, leaking cartridge |
| Faded print | Low toner or ink |
| Garbled print | Wrong or damaged driver |
| Paper not feeding | Worn or dirty pickup roller |
| Several sheets feed at once | Damp paper, worn separation pad. Fan the paper |
| Grinding noise | Broken gear or foreign object. Stop and inspect |
| Prints stuck pending, frozen queue | Clear the queue, restart the Print Spooler service |
| Wrong orientation | Portrait or landscape setting |
| Staple jam or punch problems | Clear the jam, load staples, empty the punch bin |
