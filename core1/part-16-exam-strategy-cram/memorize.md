## Exam facts

| Question | Answer |
|---|---|
| Core 1 exam code | 220-1201 |
| Maximum questions / time | 90 / 90 minutes |
| Question types | Multiple choice and performance-based questions (PBQs) |
| Passing score | 675 on a scale of 100 to 900 |
| Biggest domain | Hardware and Network Troubleshooting, 28% |
| Domain weights | Troubleshooting 28%, Hardware 25%, Networking 23%, Mobile 13%, Virtualization and Cloud 11% |
| Blank answers | Score nothing. Never leave a question blank |
| Retake rules | Fail once: retake any time. From the second failure: wait 14 calendar days |
| ID on exam day | Two valid IDs, names matching your booking exactly |

## Technique

| Question | Answer |
|---|---|
| A PBQ you do not recognise | Flag it, do the multiple choice first, come back, read the whole task, never leave it blank |
| Stuck on a question for about 30 seconds | Pick your best answer, flag it, move on |
| Time per question | About 1 minute |
| Two answers both look right | Re-read the key word (FIRST, BEST, MOST LIKELY, NOT). Choose the simple, low-risk step that fits the exact situation |
| Key words to watch | FIRST, BEST, MOST LIKELY, NOT, LEAST |
| Is the six-step troubleshooting method tested in 220-1201? | No. It is a useful work habit |
