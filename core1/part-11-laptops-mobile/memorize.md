## Laptop hardware

| Question | Answer |
|---|---|
| Laptop RAM form factor | SODIMM |
| Laptop drive types | 2.5-inch (7 mm or 9.5 mm) or M.2 |
| Where does the Wi-Fi card connect? | M.2 slot (older: mini PCIe) |
| How many antenna leads on a Wi-Fi card? | Usually two, often marked main and aux |
| Where do antenna wires run? | Through the hinge to the screen bezel |
| Weak Wi-Fi after replacing the card | Antenna leads not reconnected |
| Biometrics examples | Fingerprint reader, facial recognition |
| First steps before opening a laptop | Shut down, unplug the charger, disconnect the battery, ESD strap |
| Battery types | Lithium-ion, lithium-polymer |

## Connections and accessories

| Question | Answer |
|---|---|
| USB-C pin count and shape | 24 pins, reversible |
| Lightning pin count | 8 pins, reversible, Apple |
| miniUSB and microUSB pin count | 5 pins, not reversible |
| NFC range | About 4 cm |
| Bluetooth range | About 10 m |
| Tethering is | Sharing a phone's internet with other devices |
| Docking station vs port replicator | Dock = adds ports, charging and extras. Port replicator = just repeats the laptop's own ports |
| A track point is | The pointing stick between the G, H and B keys |

## Cellular, Bluetooth, location, MDM

| Question | Answer |
|---|---|
| SIM stands for | Subscriber Identity Module |
| nano-SIM size | 12.3 x 8.8 mm |
| eSIM is | Built into the phone, set up by QR code or profile |
| Bluetooth pairing steps | Enable Bluetooth, enable pairing, find device, enter PIN, test |
| Most accurate location method | GPS (satellites) |
| Location that works indoors via towers | Cellular location |
| MDM stands for | Mobile Device Management |
| BYOD stands for | Bring Your Own Device |
| MDM policy examples | Passcode, encryption, remote lock, remote wipe |
| What to watch when syncing on cellular | Data caps |
| Items that sync | Calendar, contacts, mail, cloud storage |
