# Exam check: Motherboards, CPUs and Firmware

Cover the answers and try each one out loud first.

**1.** A company wants to stop staff booting work PCs from their own USB drives, and stop them undoing that setting. What do you do?
<details><summary>Answer</summary>Disable USB boot in the firmware, then set a BIOS (supervisor) password so the setting can't be changed.</details>

**2.** A customer wants the smallest possible PC that still takes one full-size graphics card. Which motherboard form factor?
<details><summary>Answer</summary>Mini-ITX, which has a single expansion slot.</details>

**3.** A technician fits a new cooler and the PC now overheats and shuts down within minutes. What was most likely missed?
<details><summary>Answer</summary>Fresh thermal paste between the processor and the heat sink.</details>

## More practice (written for this kit)

**4.** A user's new CPU is the right brand and the latest model, but it physically will not go into their motherboard. Most likely cause?
<details><summary>Answer</summary>Socket mismatch. The CPU and motherboard use different sockets.</details>

**5.** A virtual machine refuses to start and reports that hardware virtualization is turned off. Where do you fix it?
<details><summary>Answer</summary>In the BIOS/UEFI firmware: enable Intel VT-x or AMD-V.</details>

**6.** A two-year-old PC is told Windows 11 isn't supported. Which two firmware features do you check first?
<details><summary>Answer</summary>TPM (version 2.0) and Secure Boot. Both can be present but switched off.</details>

**7.** Which connector carries data only (no power) for an external drive?
<details><summary>Answer</summary>eSATA.</details>

**8.** A PCIe slot is physically x16 but a graphics card runs slower than expected. What might explain it?
<details><summary>Answer</summary>The slot may be wired for fewer lanes (for example x4). Check the motherboard manual.</details>
