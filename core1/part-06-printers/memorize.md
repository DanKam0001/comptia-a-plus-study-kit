## Printer types

| Question | Answer |
|---|---|
| Which printer uses toner and a fuser? | Laser |
| Which printer sprays liquid ink from a printhead? | Inkjet |
| Which printer needs special heat-sensitive paper and has no ink? | Thermal |
| Which printer can print through carbon-copy layers? | Impact (pins hit a ribbon) |

## Setup and drivers

| Question | Answer |
|---|---|
| PCL stands for (CompTIA's wording) | Printer Control Language. Common everyday printer language |
| PostScript is used for | Graphics and professional publishing. Made by Adobe |
| Three connection methods | USB, Ethernet, wireless |
| Printer share vs print server | Share = through one PC, which must be on. Print server = on the network, always available, holds the queue |
| Why update printer firmware? | Bug fixes and security patches |

## Settings and security

| Question | Answer |
|---|---|
| Duplex | Printing on both sides |
| Portrait vs landscape | Portrait = tall, landscape = wide |
| Secured print | Job waits until the owner signs in at the printer |
| Badging | Tapping an ID badge to use the printer |
| Audit log | Records who printed or scanned what, and when |
| Network scan destinations | Email, SMB shared folder (port 445), cloud services |
| ADF vs flatbed | ADF = stack of pages. Flatbed = single sheets, books, fragile items |

## Maintenance

| Question | Answer |
|---|---|
| Laser maintenance list | Replace toner, apply maintenance kit, calibrate, clean |
| What is in a maintenance kit? | Replacement parts for worn components, such as rollers and the fuser |
| Inkjet maintenance list | Clean printheads, replace cartridges, calibrate, clear jams |
| Thermal maintenance list | Replace paper, clean heating element, remove debris |
| Thermal printer parts to know | Feed assembly, special thermal paper, heating element |
| Impact maintenance list | Replace ribbon, printhead and paper (multipart) |
| Hot part inside a laser printer | The fuser. Let it cool before opening |
