## Panel types

| Question | Answer |
|---|---|
| IPS stands for / best at | In-Plane Switching / color accuracy and wide viewing angles |
| TN stands for / best at | Twisted Nematic / fastest response and lowest cost (poor angles) |
| VA stands for / best at | Vertical Alignment / contrast and deep blacks |
| OLED stands for | Organic Light-Emitting Diode |
| Does OLED have a backlight? | No. Each pixel makes its own light |
| OLED weakness | Burn-in from long static images |
| Mini-LED is | An LCD with thousands of tiny LEDs in local dimming zones |

## Resolution

| Question | Answer |
|---|---|
| HD | 1280 x 720 |
| Full HD | 1920 x 1080 |
| QHD | 2560 x 1440 |
| 4K UHD | 3840 x 2160 |
| 8K | 7680 x 4320 |
| Pixel density unit | PPI, pixels per inch |
| Smaller screen, same resolution | Higher pixel density (sharper) |

## Refresh and color

| Question | Answer |
|---|---|
| Refresh rate unit | Hertz (Hz), redraws per second |
| Common refresh rates | 60 Hz office; 120, 144, 165, 240 Hz gaming |
| Baseline color standard | sRGB |
| DCI-P3 vs sRGB | About 25% more colors |
| Color gamut means | The range of colors a screen can show |

## Touch and inverter

| Question | Answer |
|---|---|
| Digitizer | Layer over the display that senses touch |
| Capacitive vs resistive | Finger electricity (multi-touch) vs pressure (gloves, stylus) |
| Inverter | Powers the CCFL backlight tube of an older LCD |
| Failing inverter symptom | Very dim or flickering screen, faint picture visible with a flashlight |
| Which displays need no inverter? | LED-backlit LCDs and OLED |
