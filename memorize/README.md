# What to understand vs what to memorise

A+ rewards understanding, because scenario questions are worded differently every time. But some things you can't
reason your way to. You have to know them. This folder and the `memorize.md` file in each part collect those facts.

| Understand (so you can reason) | Memorise (just know it) |
|---|---|
| Why a CPU won't fit a board | Socket names, form-factor sizes |
| What DHCP does and what happens when it fails | Port numbers and protocol names |
| Why thermal paste matters | Connector pin counts, cable types |
| What Secure Boot protects against | Acronym expansions |

## How to use it

1. Watch the video for the part.
2. Open that part's `memorize.md` and the matching CSV in `flashcards/`.
3. Import the CSV into a flashcard app (Anki works: Import, comma separated, first row is the header).
4. Review a little every day. Short, spaced reviews beat one long cram.

## Files

- `ports-and-protocols.md` + `flashcards/ports.csv` (Core 1 objective 2.1)
- Per part: `core1/part-NN-*/memorize.md` + `flashcards/core1_partNN.csv`
- `glossary/terms.md`: every term shown on a corner card in the videos
