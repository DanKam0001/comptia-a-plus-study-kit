# PBQ practice

The real A+ exams include performance-based questions (PBQs): hands-on style tasks such as matching, ordering steps, choosing settings on a screen, or fixing a scenario. A text kit can't run a simulator, so these are printable tasks you do on paper or in a text file. Each part has **2 PBQs** of different types, mapped to that part's objectives.

## How to use them

1. Watch the part's video and read its cheat sheet.
2. Open the part's `-pbq.md` file and do each task against the clock (the time guide is on each one).
3. Only then open the matching `-pbq-answers.md` file and mark yourself. Each answer has a one-line reason, and the marking gives partial credit per item.
4. Missed items? The objective number on each PBQ tells you which part to rewatch.

> The marking and time guides are this kit's own, for practice. CompTIA doesn't publish how PBQs are scored, so don't read anything into the points. Exam-day numbers used in the exam strategy parts (Core 1 Part 16, Core 2 Part 17) are invented for the exercise.
