## C2P17-PBQ1: Build the time budget

| | |

**Scenario (a made-up exercise, not CompTIA data).** You are sitting a practice Core 2 exam. It has 90 questions and gives you 90 minutes. Three of the 90 questions are PBQs. The other 87 are multiple choice. Your plan: keep 15 minutes at the end for review, and give each PBQ 5 minutes on your first pass.

**Task.**

**Part A.** Fill in the time budget. Use whole numbers. For the seconds, round down to a whole second.

| # | Item | Your answer |
|---|---|---|
| 1 | Total minutes for the 3 PBQs on the first pass | |

| 3 | Minutes left for the 87 multiple choice questions | |
| 4 | About how many seconds per multiple choice question (line 3 in seconds, divided by 87) | |
| 5 | The minute on the clock when review starts (counting up from 0 to 90) | |

**Part B.** Pick the best action for each situation. Write the letter. Letters can be used more than once.

| Letter | Action |
|---|---|
| A | Pick your best answer, flag it, move on |
| B | Answer every question, guessing where you must |
| C | Do the parts you know, flag it, return later |
| D | Leave it blank, a wrong answer is worse than none |

## C2P17-PBQ2: Flag and return in the right order

| | |
|---|---|
| **ID** | C2P17-PBQ2 |
| **Objectives** | Exam strategy (all objectives, 220-1202) |
| **Type** | Ordering (number the actions) |
| **Time guide** | 5 minutes |

**Scenario.** Question 1 of your exam is a PBQ you only half recognise. The rest are multiple choice. Use the rules below, then put your actions in order.

**Rules for this task.** The flagged list opens in question-number order. You have enough time to finish everything. Review starts when about 15 minutes remain.

**Task.** Number the actions 1 to 7 in the order you would do them. One action is a bad idea: leave it blank.

| Your number | Action |
|---|---|
| | Check that no question is left blank. |
| | Spend 20 minutes perfecting PBQ 1 before looking at any other question. |
| | Finish the flagged PBQ 1. |
| | Read PBQ 1, do the parts you know, flag it and move on. |
| | At about 15 minutes left (every question already has an answer), open the flagged list. |
| | Submit the exam. |
| | Review the remaining flagged multiple choice questions. |
| | Work through the multiple choice questions, give a best answer to every one, and flag the unsure ones. |
