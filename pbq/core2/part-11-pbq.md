## C2P11-PBQ1: Choose the right method

| | |
|---|---|
| **ID** | C2P11-PBQ1 |
| **Objectives** | 2.9 |
| **Type** | Decision table with tick lists (pick from a menu, then tick what applies) |
| **Time guide** | 6 minutes |

**Scenario.** Your company is clearing out old equipment. Some drives will be donated or sold and must still work afterwards. One drive is dead and will never be used again. Everything you handle held customer data.

**Task.**

**Part A.** Write the letter of the best method beside each drive. Letters can be used more than once.

| Letter | Method |
|---|---|
| A | Delete the files |
| B | Quick (standard) format |
| C | Wipe: software overwrites the whole drive |
| D | Run the SSD maker's secure erase tool (the SSD-specific method) |
| E | Shred the drive |

| # | Drive | Your letter |
|---|---|---|
| 1 | A working hard disk drive (HDD) going to a school as a donation. It must still work. | |
| 2 | A working laptop SSD being sold online. It must still work. | |
| 3 | A dead SSD that will not power on and will never be used again. | |

**Part B.** A recycler offers to run your items through a degausser. Tick every item where a degausser will actually remove the data.

- [ ] Hard disk drive (HDD)
- [ ] Solid-state drive (SSD)
- [ ] Backup tape
- [ ] USB flash drive
- [ ] Smartphone

**Part C.** A third-party vendor is destroying your drives and must hand you a certificate of destruction. Tick the THREE things that belong on that certificate.

- [ ] Serial number of each drive
- [ ] The date of destruction
- [ ] The method used
- [ ] The password of the person who owned each drive
- [ ] The colour of the drives
- [ ] The vendor's lunch menu

| 4 | Degaussing destroys the data on SSDs. | | |
