## C2P07-PBQ1: Sort the proofs of identity

| | |
|---|---|
| **Objectives** | 2.1 |
| **Type** | Categorize (drag and drop into columns) |
| **Time guide** | 6 minutes |

**Scenario.** Your company is adding multifactor authentication (MFA). A factor is a kind of proof: something you **know**, something you **have**, or something you **are**.

**Part A.** Put each of the ten items into **one** column by writing its letter.

| Letter | Item |
|---|---|
| A | Password |
| B | Smart card |
| C | Fingerprint |
| D | PIN |
| E | Hardware token that shows a code |
| F | Retina scan |
| G | Key fob |
| H | Authenticator app on your phone |
| I | Facial recognition |
| J | Voice recognition |

| Something you KNOW | Something you HAVE | Something you ARE |
|---|---|---|
| | | |

**Part B.** Is each pair of proofs **multifactor** (two or more *different* kinds)? Write **Yes** or **No**.

| Pair | Multifactor? |
|---|---|
| 1. Password and PIN | |
| 2. Password and a code from an authenticator app | |
| 3. Smart card and fingerprint | |
| 4. Fingerprint and facial recognition | |

**Marking.** 14 points: 1 point per item in Part A (10) and 1 point per pair in Part B (4).

## C2P07-PBQ2: Choose the security setting

| | |
|---|---|
| **Objectives** | 2.1, 2.3 |
| **Type** | Configure this form |
| **Time guide** | 7 minutes |

**Scenario.** You are securing a small company's office and wireless network. Below is a text form with nine rows. For each row choose **one option** from that row's list.

| Row | What is needed | Options | Your choice |
|---|---|---|---|
| 1 | The new router and every device support the newest and strongest Wi-Fi security. Pick the security mode. | WPA3, WPA2, TKIP | |
| 2 | The router is set to WPA2. Pick the encryption it should use. | AES, TKIP | |
| 3 | Wi-Fi and VPN logins must all be checked by one central server for network access. | RADIUS, TACACS+, Kerberos | |
| 4 | Administrator sign-ins to the company's routers and switches must be controlled and logged. | RADIUS, TACACS+, Kerberos | |
| 5 | Windows domain users should sign in with a ticket so their password is not sent again and again. | RADIUS, TACACS+, Kerberos | |
| 6 | People keep following staff through the front door without using a badge. | Bollards, Access control vestibule, Video surveillance, Badge reader | |
| 7 | A vehicle could be driven into the glass entrance. | Bollards, Access control vestibule, Video surveillance, Badge reader | |
| 8 | The manager wants to check who was at the door last night. | Bollards, Access control vestibule, Video surveillance, Badge reader | |
| 9 | A contractor needs administrator rights for one hour, and then the rights must be removed again. | Just-in-time access, Principle of least privilege, Zero Trust model, SSO | |

**Marking.** 9 points: 1 point per row.
