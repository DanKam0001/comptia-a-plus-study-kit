## C2P13-PBQ1: Match the phone problem to the first fix

| | |
|---|---|
| **ID** | C2P13-PBQ1 |
| **Objectives** | 3.2 |
| **Type** | Matching (drag and drop on paper: write one letter beside each problem) |
| **Time guide** | 5 minutes |

**Scenario.** You are working a phone support desk. Eight users call in with ordinary software problems. None of them has malware.

**Task.** Write the letter of the best first fix beside each problem. Each letter is used at most once. Two answers are not used.

**Materials**

| # | Problem | Your letter |
|---|---|---|
| 1 | A Bluetooth speaker that was paired before will not connect now. | |
| 2 | The phone cannot join Wi-Fi and a plane icon shows at the top. | |
| 3 | Tap-to-pay (NFC) fails. The phone is in a thick case. | |
| 4 | The screen stays upright when the phone is turned sideways. | |
| 5 | An OS update fails and the message says storage is full. | |
| 6 | The battery empties very quickly and you want to find the cause. | |
| 7 | An app crashes every time it launches. | |
| 8 | The router was changed. The saved home Wi-Fi shows but will not connect. | |

| Letter | Answer |
|---|---|
| A | Forget the Bluetooth device and pair it again |
| B | Turn airplane mode off |
| C | Remove the case and hold the phone within a few centimetres of the reader |
| D | Turn off rotation lock |
| E | Free up storage space |
| F | Check battery usage by app |
| G | Force close the app, restart the phone, then update or reinstall the app |
| H | Forget the Wi-Fi network and rejoin it |
| I | Root the phone |
| J | Install the app again from a website outside the official store |

## C2P13-PBQ2: Triage the security problems

| | |
|---|---|
| **ID** | C2P13-PBQ2 |
| **Objectives** | 3.3, 3.4 |
| **Type** | Triage form (choose a cause and an action from lists), plus term matching |
| **Time guide** | 7 minutes |

**Scenario.** Four tickets arrive about PCs and phones that may be infected, and you need to fill in a triage form for each. Afterwards you check four words that come up in the notes.

**Task.**

**Part A.** For each ticket, write one letter from the Cause list and one number from the Action list. Each item can be used once or not at all.

Cause list:

| Letter | Cause |
|---|---|
| A | Ransomware |
| B | Rogue antivirus (fake security alert) |
| C | Malicious browser extension or changed proxy or DNS settings |
| D | Sideloaded malicious app |
| E | Application spoofing |
| F | Jailbroken phone |

Action list:

| Number | Action |
|---|---|
| 1 | Isolate the PC, do not pay, restore from backup |
| 2 | Do not click or call, scan with real anti-malware |
| 3 | Remove the extension, check proxy and DNS, scan |
| 4 | Remove the app, scan, install only from the official store |
| 5 | Turn on developer mode |
| 6 | Ignore it, it will pass |
