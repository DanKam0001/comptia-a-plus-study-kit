## C2P06-PBQ1: Will the app install and run?

| | |
|---|---|
| **Objectives** | 1.10 |
| **Type** | Fill-in table |
| **Time guide** | 6 minutes |

**Scenario.** Before installing anything, you check each app's requirements against the PC it is meant for. In each row, **only one** thing can be wrong, or nothing is wrong.

**Task.** For each row write **Yes** (it will install and run) or **No**. If No, write the **letter** of the one cause from the list.

**Materials: causes**

| Letter | Cause |
|---|---|
| A | The app is 64-bit but the OS is 32-bit |
| B | No dedicated graphics (and not enough VRAM) |
| C | An external hardware token is missing |
| D | Not enough free storage |
| E | Not enough RAM |
| F | The app is not built for this OS |

| Row | The app | The PC | Yes or No | Cause letter |
|---|---|---|---|---|
| 1 | Design software, 64-bit only. | 32-bit Windows. The CPU, RAM and storage are all fine. | | |
| 2 | Accounting software that needs a license dongle (a small USB key) to start. | Meets every spec, but the dongle is in a drawer, not plugged in. | | |
| 3 | A 3D game that needs a dedicated graphics card with 4 GB of VRAM. | Meets every spec, but has only integrated graphics. | | |
| 4 | Video editor that needs 20 GB of free disk space. | Meets every spec, but has only 8 GB free. | | |
| 5 | Spreadsheet app built for Windows 11. Needs 4 GB RAM and 10 GB free storage. | 64-bit Windows 11, 8 GB RAM, 100 GB free. | | |
| 6 | An app made only for Windows. | A Mac running macOS. Everything else is fine. | | |

**Marking.** 6 points: 1 point per row. For rows 1 to 4 and 6 you need the No **and** the right letter. For row 5 you need Yes with no letter.

## C2P06-PBQ2: Installing and cloud tools, match the fix

| | |
|---|---|
| **Objectives** | 1.10, 1.11 |
| **Type** | Matching |
| **Time guide** | 5 minutes |

**Scenario.** A small company is moving to cloud tools and installing new software. Eight requests reach you. Each has exactly one best answer.

**Task.** Match each request (1 to 8) to **one** answer (A to H). Each answer is used **exactly once**.

**Materials: answers**

| Letter | Answer |
|---|---|
| A | Cloud email |
| B | Cloud collaboration tool |
| C | Downloadable package |
| D | Identity synchronization |
| E | Image deployment |
| F | License assignment |
| G | Mountable ISO file |
| H | Cloud storage sync and folder settings |

**Requests**

1. The software is on a disc image, and the laptop has no disc drive.
2. A user wants to choose which folders sync to the laptop, and which files stay online-only.
3. A new user can sign in, but the cloud spreadsheet app says there is no license.
4. A team wants to edit one spreadsheet in a browser at the same time.
5. Staff should have one set of sign-in details that stays the same between the on-premises Active Directory and the cloud.
6. The same install is needed on 50 identical PCs, and IT wants to copy one ready-made system image to all of them.
7. The installer is a file downloaded from the vendor's site and run on the PC.
8. Mail is kept on the provider's servers so it can be reached from any device, as with Gmail or Outlook with Microsoft 365.

**Marking.** 8 points: 1 point per correct match.
