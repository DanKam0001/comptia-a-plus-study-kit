## C2P09-PBQ1: Put the malware removal steps in order

| | |
|---|---|
| **Objectives** | 2.6 |
| **Type** | Ordering |
| **Time guide** | 6 minutes |

**Scenario.** A staff member's PC in a small office is acting strangely and you suspect malware. CompTIA lists ten steps for basic SOHO malware removal. They are shuffled below.

**Task.** Write the letters in the correct order, from step 1 to step 10. Assume every step is needed.

**Materials: the steps (shuffled)**

| Letter | Step |
|---|---|
| A | Schedule scans and run updates |
| B | Enable System Restore and create a restore point in Windows Home |
| C | Quarantine the infected system |
| D | Remediate infected systems |
| E | Educate the end user |
| F | Reimage or reinstall |
| G | Disable System Restore in Windows Home |
| H | Investigate and verify malware symptoms |
| I | Scan and removal techniques (for example safe mode, preinstallation environment) |
| J | Update anti-malware software |

**Marking.** 10 points: 1 point for each step that is in the right position.

## C2P09-PBQ2: Name that threat

| | |
|---|---|
| **Objectives** | 2.4, 2.5 |
| **Type** | Matching |
| **Time guide** | 7 minutes |

**Scenario.** Ten reports land in the security inbox. Each matches exactly one threat from the list.

**Task.** Match each report (1 to 10) to **one** threat (A to L). Each threat is used **at most once**, and two are not needed.

**Materials: threats**

| Letter | Threat |
|---|---|
| A | Cryptominer |
| B | Dumpster diving |
| C | Evil twin |
| D | Keylogger |
| E | Ransomware |
| F | Rootkit |
| G | Shoulder surfing |
| H | Smishing |
| I | Virus |
| J | Trojan |
| K | Whaling |
| L | Zero-day attack |

**Reports**

1. A PC is slow and hot, the fans are loud, and the CPU sits at 100 percent for no reason you can find.
2. A text message about a missed parcel contains a link.
3. A fake email, made to look like it is from a supplier, is aimed at the company's CEO.
4. All the files on a PC are locked and a message demands payment.
5. A Wi-Fi network appears with the same name as the cafe's real network, but it is a fake.
6. Malware survives every antivirus scan and keeps coming back, because it hides deep in the operating system.
7. Someone stands behind a user and reads the PIN as it is typed.
8. A program records every key a user presses so that it can steal their passwords.
9. Someone searches the office bin for printed passwords.
10. An attacker uses a flaw in software that nobody has patched yet, because no fix exists.

**Marking.** 10 points: 1 point per correct match.
