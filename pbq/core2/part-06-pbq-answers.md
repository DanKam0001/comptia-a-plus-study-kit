## C2P06-PBQ1: Will the app install and run?

| Row | Answer | Why |
|---|---|---|
| 1 | No, A | A 64-bit app needs a 64-bit OS |
| 2 | No, C | An external hardware token (dongle) proves you own the license; the app will not run without it plugged in |
| 3 | No, B | Games and 3D want a dedicated card; integrated graphics is built into the CPU and shares system RAM |
| 4 | No, D | Free disk space is needed for the install and for the data it creates |
| 5 | Yes, no letter | Meets the app-to-OS, RAM and storage requirements |
| 6 | No, F | Application-to-OS compatibility: an app built for Windows does not run on macOS |

Letter E (RAM) is not the answer to any row.

**Partial credit (6 points):** 1 per row. Rows 1 to 4 and 6 need both No and the right letter; row 5 needs Yes. 6 = full marks. 4 to 5 = pass-level. 3 or fewer = reread the requirements table.

## C2P06-PBQ2: Installing and cloud tools, match the fix

| # | Answer | Why |
|---|---|---|
| 1 | G, Mountable ISO file | Windows mounts the ISO as a virtual drive, so no disc drive is needed |
| 2 | H, Cloud storage sync and folder settings | Choose which folders sync and online-only versus kept on the device |
| 3 | F, License assignment | Cloud apps are paid per user; an admin assigns a license to the account |
| 4 | B, Cloud collaboration tool | Word processing, spreadsheet and similar tools let several people edit at once |
| 5 | D, Identity synchronization | Keeps sign-in details the same between on-premises Active Directory and the cloud |
| 6 | E, Image deployment | One prepared image copied to many computers |
| 7 | C, Downloadable package | A file you download and run |
| 8 | A, Cloud email | Mail lives on the provider's servers and any device can reach it |

**Partial credit (8 points):** 1 per match. 7 to 8 = strong. 5 to 6 = pass-level. 4 or fewer = reread the distribution methods and cloud tools sections.
