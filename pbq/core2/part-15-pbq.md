## C2P15-PBQ1: Match the situation to the control

| | |
|---|---|
| **ID** | C2P15-PBQ1 |
| **Objectives** | 4.4, 4.5 |
| **Type** | Matching (drag and drop on paper: write one letter beside each situation) |
| **Time guide** | 5 minutes |

**Scenario.** You are setting up and cleaning a small repair workshop. Eight everyday situations come up in one afternoon.

**Task.** Write the letter of the best answer beside each situation. Each letter is used at most once. Two answers are not used.

**Materials**

| # | Situation | Your letter |
|---|---|---|
| 1 | The power cuts out for a moment and PCs keep running long enough to shut down safely. | |
| 2 | A sudden voltage spike arrives during a storm. | |
| 3 | You need the handling and disposal instructions for a toner cartridge. | |
| 4 | You are carrying a loose stick of RAM to another desk. | |
| 5 | You want static to drain away from you instead of into a part. | |
| 6 | Dust is building up inside a PC's vents. | |
| 7 | An old laptop battery needs to go somewhere safe. | |
| 8 | You must move a heavy printer. | |

| Letter | Answer |
|---|---|
| A | Uninterruptible power supply (UPS) |
| B | Surge suppressor |
| C | MSDS (material safety data sheet) |
| D | Antistatic bag |
| E | ESD strap clipped to bare metal on the case |
| F | Compressed air or a vacuum |
| G | Recycling or hazardous-waste collection |
| H | Bend your knees, keep your back straight, lift with your legs |
| I | The normal office rubbish bin |
| J | Spray it with water |

| | |
|---|---|

**Scenario.** You visit a customer whose PC is slow. The customer is rude and impatient. While you work, you notice something on the PC that looks like prohibited content, so you will also need to handle that properly.

**Task.**

**Part A.** Write **DO** or **DON'T** beside each behaviour.

| 5 | Tell the customer it is nothing serious | |
| 6 | Contact the customer if you will be late | |
