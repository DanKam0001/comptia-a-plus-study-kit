## C1P11-PBQ1: Swap a Laptop Wi-Fi Card

| | |
|---|---|
| **ID** | C1P11-PBQ1 |
| **Objectives** | 1.1 |
| **Type** | Ordering (number the steps) |
| **Time guide** | 4 minutes |
| **Points** | 7 (1 per step in the right place) |

### Scenario

A laptop's Wi-Fi card has failed and you have a new one. You will open the laptop, replace the card and check that it works. The steps below are in a mixed-up order.

### Task

Write the numbers 1 to 7 next to the steps, with 1 for the first thing you do and 7 for the last. Use each number once.

### Materials

| Letter | Step | Your number |
|---|---|---|
| A | Fit the new wireless card into its M.2 slot | |
| B | Open the case, photographing how things sit and keeping screws in labelled piles, then disconnect the battery | |
| C | Reconnect the battery and power on the laptop | |
| D | Shut down the laptop, unplug the charger and put on an ESD strap | |
| E | Test the Wi-Fi signal | |
| F | Unsnap the two antenna leads (main and aux) and remove the old card | |
| G | Snap the two antenna leads onto the new card | |

## C1P11-PBQ2: Mobile Setup Form

| | |
|---|---|
| **ID** | C1P11-PBQ2 |
| **Objectives** | 1.2, 1.3 |
| **Type** | Configure this (pick the right option for each field) |
| **Time guide** | 6 minutes |
| **Points** | 11 (1 per field) |

### Scenario

You support a company with laptops and phones. A form lists six situations and a few connector facts to confirm before a hardware order goes out.

### Task

**Part A.** For each situation pick the one best option from the list. Two options are not used.

**Part B.** Fill in each blank with a number or Yes or No.

### Materials

**Part A options:** Docking station, Tethering (hotspot), NFC, MDM, BYOD, eSIM, Lightning, Port replicator.

| Field | Situation | Your answer |
|---|---|---|
| A1 | One connection to a laptop gives it a screen, keyboard, network and charging, and can add extra ports and features | |
| A2 | A phone shares its internet connection with a laptop | |
| A3 | A user holds a phone about 4 cm from a reader to pay | |
| A4 | The company must enforce passcodes and send a remote wipe to its phones from one console | |
| A5 | Staff use their own phones for work, and the work data lives in a separate work profile | |
| A6 | A phone has no SIM card to swap. The plan is set up by scanning a QR code | |

**Part B**

| Field | Question | Your answer |
|---|---|---|
| B1 | How many pins does USB-C have? | |
| B2 | Is USB-C reversible? (Yes or No) | |
| B3 | How many pins does Lightning have? | |
| B4 | How many pins do miniUSB and microUSB have? | |
| B5 | Is microUSB reversible? (Yes or No) | |
