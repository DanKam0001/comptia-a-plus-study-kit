## C1P04-PBQ1: Power supply workbench sheet

- **Objective:** 3.6
- **Type:** Fill-in table (with a short ordering task)
- **Time guide:** 7 minutes

### Scenario

You are replacing a power supply (PSU) in a customer's PC. The new PSU has loose wires and several connector plugs, and it has a manual voltage switch. You also have to choose between PSUs with different efficiency badges. Fill in the sheet.

### Materials

**Part A: wire colours.** Match the colour to what it carries. Choices: `3.3 V`, `5 V`, `12 V`, `ground`.

| Wire colour | Carries |
|---|---|
| Orange | |
| Red | |
| Yellow | |
| Black | |

**Part B: connectors.** Write the connector that does each job. Choices: `20+4 pin`, `4+4 pin (8 pin)`, `6+2 pin (8 pin)`, `15-pin SATA`, `4-pin Molex`, `RJ45`.

| Job | Connector |
|---|---|
| Main power to the motherboard | |
| Power to the CPU, near the processor | |
| Power to the graphics card | |
| Power to a SATA drive | |
| Legacy 4-pin power for an old drive or fan | |

**Part C: efficiency.** These five 80 PLUS badges are mixed up: `Gold`, `Titanium`, `Bronze`, `Platinum`, `Silver`. Write them in order from the **lowest** efficiency to the **highest**.

**Part D: input voltage.** The customer's wall outlet supplies 230 VAC. Which switch position should the PSU be set to? Choices: `110-120 VAC` or `220-240 VAC`.

### Task

Complete Parts A to D.

### Marking

15 points: Part A 4, Part B 5, Part C 5 (1 per correct position), Part D 1.

## C1P04-PBQ2: Match the cable to the job

- **Objective:** 3.2
- **Type:** Matching
- **Time guide:** 6 minutes

### Scenario

You are a technician for a small office. Seven jobs need a cable or connector each. The parts list has nine entries, so two are not needed. Match each job to the one best entry.

### Materials

**Jobs**

1. A 10 Gbps link over a 90 metre copper run.
2. A cable that will run above the ceiling tiles, in the air-handling space.
3. A link between two buildings about 5 kilometres apart.
4. The cable from the internet provider's wall box that uses a screw-on connector, for cable broadband.
5. A cable to reach the console port on a switch (RS-232, with a DB-9 connector).
6. A copper cable through a factory floor full of electrical noise from heavy machines.
7. A cable going into the ground to a garden office.

**Parts list**

- **A.** Cat 6a
- **B.** Plenum-rated cable
- **C.** Single-mode fiber
- **D.** Multimode fiber
- **E.** Coaxial cable with an F-type connector
- **F.** Serial cable with a DB-9 connector
- **G.** STP (shielded twisted pair)
- **H.** Direct burial cable
- **I.** Cat 5

### Task

Write the letter for each job number. Each letter is used at most once.

### Marking

7 points: 1 per job.
