# Core 1, Part 16: PBQ practice (Exam Strategy: Triaging a PBQ-heavy Exam)

Two performance-based question (PBQ) drills for **exam technique on 220-1201** (this part adds no new objective). They are not technical questions. They practise how to spend 90 minutes when PBQs are on screen. Print this page or copy the blanks into a text file. Do the tasks **before** you open [`part-16-pbq-answers.md`](part-16-pbq-answers.md). Facts come from the Part 16 [cheatsheet](../../core1/part-16-exam-strategy-cram/cheatsheet.md) and [memorise sheet](../../core1/part-16-exam-strategy-cram/memorize.md).

## C1P16-PBQ1: Exam Clock Budget

| | |
|---|---|
| **ID** | C1P16-PBQ1 |
| **Objectives** | Exam technique (all Core 1 objectives) |
| **Type** | Fill-in table (time budgeting) |
| **Time guide** | 5 minutes |
| **Points** | 8 (1 per blank) |

### Scenario

You sit a practice paper with 90 questions and 90 minutes on the clock. Imagine four of the questions are PBQs. **This is an exercise:** the number of PBQs and the 50, 5 and 10 minute figures below are invented for this drill. CompTIA does not publish how many PBQs you will get or how to split the time. The only official facts here are the exam limits of a maximum of 90 questions in 90 minutes. The 30 second and 10 minute rules in Part A are this kit's rules of thumb, not CompTIA rules. Your plan is to skip the PBQs at the start, finish the multiple choice questions, then do the PBQs, then review, and keep the last stretch for a blank check.

### Task

**Part A.** Fill in the three blanks from the exam technique rules.

**Part B.** Complete the plan, using these fixed numbers:

- The multiple choice pass takes 50 minutes.
- Each of the 4 PBQs gets 5 minutes.
- The final blank check takes 10 minutes.
- Whatever time is left over is the review block for flagged questions.

The clock counts **down** from 90, and the checkpoints below are the minutes **remaining on the clock** when each block starts.

### Materials

**Part A**

| # | Question | Your answer |
|---|---|---|
| A1 | With 90 questions in 90 minutes, about how many minutes do you have per question? | |
| A2 | Stuck on a question for about how many seconds before you pick your best answer, flag it and move on? | |
| A3 | With about how many minutes left on the clock do you fill in anything still blank? | |

**Part B**

| # | Question | Your answer |
|---|---|---|
| B1 | How many minutes does the PBQ block take (4 PBQs at 5 minutes each)? | |
| B2 | How many minutes are left for the review block? | |

## C1P16-PBQ2: Flag and Return Ordering

| | |
|---|---|
| **ID** | C1P16-PBQ2 |
| **Objectives** | Exam technique (all Core 1 objectives) |
| **Type** | Ordering (number the steps) |
| **Time guide** | 3 minutes |
| **Points** | 6 (1 per step in the right place) |

### Scenario

The exam opens and the first screen is a PBQ you do not recognise. You want to bank easy points, never leave anything blank, and still have time for the hard PBQs.

### Task

Write the numbers 1 to 6 next to the steps, with 1 for the first thing you do and 6 for the last. Use each number once.

Plan rules for this drill:
- Return to the flagged PBQs **before** you review flagged multiple choice questions, because a blank PBQ can never score.
- The final blank check always comes last.

### Materials

| Letter | Step | Your number |
|---|---|---|
| A | Read the whole PBQ task, do the parts you know, then fill in every remaining part | |
| B | Answer the multiple choice questions. If you are stuck for about 30 seconds, pick your best answer, flag it and move on | |
| C | With about 10 minutes left, fill in any question that is still blank | |
| D | The first screen is a PBQ you do not recognise: flag it and move on | |
| E | Go back to the flagged PBQs with the time that is left | |
| F | Use spare time to review flagged multiple choice questions, leaving alone the answers you were sure of | |
