## C1P14-PBQ2: Ticket Queue

| | |
|---|---|
| **ID** | C1P14-PBQ2 |
| **Objectives** | 5.3, 5.4 |
| **Type** | Fix this scenario (fill in a ticket form) |
| **Time guide** | 7 minutes |
| **Points** | 10 (1 per field) |

### Scenario

Five tickets arrived at the help desk about projectors, a laptop screen and phones. For each ticket you fill in the most likely cause and the fix that solves that cause.

### Task

For each ticket write one cause number and one fix letter from the lists. Each cause and each fix is used at most once, and one of each is left over.

### Materials

**Causes**

| Number | Cause |
|---|---|
| 1 | Burnt-out bulb |
| 2 | Overheating from clogged filters and vents |
| 3 | Swollen battery |
| 4 | Digitizer fault |
| 5 | Failing backlight or inverter |
| 6 | Incorrect input source |

**Fixes**

| Letter | Fix |
|---|---|
| A | Let it cool, replace the lamp, reset the lamp-hours counter |
| B | Clean the filters and vents and leave space for airflow |
| C | Stop using it, do not charge it, replace the battery safely and recycle the old one |
| D | Replace the screen and digitizer assembly |
| E | Replace the backlight or inverter |
| F | Choose the right input in the screen's menu |

| T3 | A phone's back cover is lifting because the battery is visibly bulging | | |
| T4 | A phone's picture is perfect but it ignores every touch | | |
