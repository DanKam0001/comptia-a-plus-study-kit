## C1P10-PBQ1: Set Up the New Router

| | |
|---|---|
| **ID** | C1P10-PBQ1 |
| **Objectives** | 2.6 |
| **Type** | Ordering (number the steps) |
| **Time guide** | 3 minutes |
| **Points** | 6 (1 per step in the right place) |

### Scenario

A home office has a brand new router still in its box. You are setting it up for the first time. The six steps below are in a mixed-up order.

### Task

Write the numbers 1 to 6 next to the steps, with 1 for the first thing you do and 6 for the last. Use each number once.

Hints: cabling goes from the internet side inwards, so the line from the modem or ONT is connected before your laptop. The router's own admin login is the first security step. A Wi-Fi name and password come after it.

### Materials

| Letter | Step | Your number |
|---|---|---|
| A | Change the default admin password | |
| B | Test that a device on the new Wi-Fi can reach the internet | |
| C | Connect a laptop to one of the router's LAN ports | |
| D | Set the SSID (network name) and a strong Wi-Fi password | |
| E | Plug the internet line from the modem or ONT into the router's WAN port | |
| F | Open the router's settings page (the address is on the label) and log in with the default login | |
