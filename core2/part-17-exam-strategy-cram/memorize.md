# Memorise list: Exam Strategy, PBQs and a Cram Review (Core 2, Part 17)

Understand the video first, then learn these cold.
Flashcards: [`flashcards/core2_part17.csv`](../../flashcards/core2_part17.csv) (import into Anki or any flashcard app).

## Exam facts

| Question | Answer |
|---|---|
| Core 2 exam code | 220-1202 |
| Maximum number of questions | 90 |
| Time allowed | 90 minutes |
| Passing score | 700 (scale of 100 to 900) |
| Two question types | Multiple choice, performance-based (PBQ) |
| Domain weights | Operating Systems 28%, Security 28%, Software Troubleshooting 23%, Operational Procedures 21% |

## Technique

| Question | Answer |
|---|---|
| What to do with an unrecognised PBQ | Do what you know, flag it, return later |
| Rough time per question | About 1 minute |
| Review time to keep | 10 to 15 minutes |
| Unanswered question counts as | Wrong, so answer every question |
| Key words to look for | First, best, most likely, next |

## Tools and order lists

| Question | Answer |
|---|---|
| Event Viewer / Disk Management / Device Manager | eventvwr.msc / diskmgmt.msc / devmgmt.msc |
| Task Scheduler / Performance Monitor / Group Policy Editor | taskschd.msc / perfmon.msc / gpedit.msc |
| Local Users and Groups / Certificate Manager | lusrmgr.msc / certmgr.msc |
| System Information / System Configuration / Registry Editor | msinfo32.exe / msconfig.exe / regedit.exe |
| First two malware removal steps | Investigate and verify symptoms, then quarantine the system |
| Last malware removal step | Educate the end user |
| Incremental restore needs | Full + every incremental |
| Differential restore needs | Full + latest differential |
| 3-2-1 rule | 3 copies, 2 media types, 1 offsite |
| First step before opening a PC | Disconnect the power |
| Ports | SSH 22, RDP 3389, VNC 5900 |
