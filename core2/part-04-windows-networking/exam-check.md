# Exam check: Windows Networking on the Client

Cover the answers and try each one out loud first.

**1.** A user working from home needs to reach files on the company network, and the connection must be secure. What should they use?
<details><summary>Answer</summary>A VPN, which builds an encrypted tunnel to the company network.</details>

**2.** A laptop at a coffee shop is sharing its files with strangers on the same Wi-Fi. Which network setting should be changed?
<details><summary>Answer</summary>Set the network profile type to Public. Public hides the computer and blocks sharing.</details>

**3.** An office with 50 computers wants one sign in for everyone, with the settings controlled from one place. What should the computers join?
<details><summary>Answer</summary>A domain. A central server keeps all the accounts and pushes the settings. Workgroup PCs each keep their own accounts.</details>

## More practice (written for this kit)

**4.** A staff member uses the same shared folder every day and wants it to appear as a drive letter after every restart. What do you do?
<details><summary>Answer</summary>Map a network drive and tick "Reconnect at sign-in".</details>

**5.** A printer needs to keep the same IP address so users can always reach it. What kind of addressing should it use?
<details><summary>Answer</summary>Static, typed in by hand (or a DHCP reservation). Dynamic addresses can change.</details>

**6.** A remote tool can't reach a program on a PC from outside. What should you add to Windows Defender Firewall?
<details><summary>Answer</summary>An exception (an inbound rule or an allowed app) for that program. Don't turn the firewall off.</details>

**7.** A website loads at home but fails only on the work network. Which Windows setting might be involved?
<details><summary>Answer</summary>Proxy settings.</details>

**8.** A laptop on a phone hotspot keeps using lots of data for updates. What setting reduces this?
<details><summary>Answer</summary>Turn on Metered connection for that network.</details>

**9.** What does WWAN mean, and what is it used for?
<details><summary>Answer</summary>Wireless Wide Area Network, a cellular connection with a SIM or eSIM.</details>

**10.** A technician tries to join a PC to the company domain and the option isn't there. What edition is it most likely running?
<details><summary>Answer</summary>Windows Home, which can't join a domain.</details>
