# Memorise list: macOS and Linux (Core 2, Part 5)

Understand the video first, then learn these cold. They're the facts a scenario question assumes you already know.
Flashcards: [`flashcards/core2_part05.csv`](../../flashcards/core2_part05.csv) (import into Anki or any flashcard app).

## macOS

| Question | Answer |
|---|---|
| Finder is the Mac's | File Explorer |
| Dock is the Mac's | Taskbar |
| Spotlight shortcut | Command + Space |
| Mission Control shows | All open windows and desktops |
| Keychain is | The built in password manager |
| iCloud includes | iCloud Drive, iMessage, FaceTime |
| Continuity does | Makes a Mac and an iPhone work together |
| Force Quit shortcut | Option + Command + Esc |
| Backup tool | Time Machine |
| Drive encryption | FileVault |
| Check or erase a drive | Disk Utility |
| Command line | Terminal |
| .dmg is / how to install | Disk image: drag the app to Applications |
| .pkg is | Installer package (wizard) |
| .app is | The application itself |
| Uninstall a Mac app | Drag it to the Trash, empty the Trash |
| /Applications | Installed apps |
| /Users | Home folders |
| /Library | Settings and support files for all users |
| /System | macOS itself (protected) |
| /Users/name/Library | That user's own settings |
| RSR | Rapid Security Response: small urgent security fixes |

## Linux commands

| Command | Job |
|---|---|
| ls | List |
| pwd | Print working directory |
| mv | Move or rename |
| cp | Copy |
| rm | Remove (permanent) |
| chmod | Change permissions |
| chown | Change owner |
| grep | Search inside files |
| find | Search for files |
| fsck | Check a filesystem |
| mount | Attach a drive |
| su | Switch user |
| sudo | Run as root |
| apt | Package manager for Debian and Ubuntu |
| dnf | Package manager for Fedora and Red Hat |
| ip | Show addresses |
| ping | Test a host (runs until Ctrl + C) |
| curl | Fetch a web page or file |
| dig | DNS lookup |
| traceroute | Show hops |
| man | Manual |
| cat | Print a file |
| top | Live process list |
| ps | List processes |
| du | Disk usage |
| df | Free disk space |
| nano | Text editor (Ctrl + O save, Ctrl + X exit) |

## Linux facts

| Question | Answer |
|---|---|
| Permission numbers | read 4, write 2, execute 1 |
| chmod 755 | Owner rwx, group r-x, others r-x |
| chmod 644 | Owner rw-, group r--, others r-- |
| /etc/passwd | User accounts |
| /etc/shadow | Hashed passwords (root only) |
| /etc/hosts | Name to address map |
| /etc/fstab | Drives to mount at startup |
| /etc/resolv.conf | DNS servers |
| Kernel | The core, talks to hardware |
| Bootloader | Starts the kernel |
| systemd | Starts and manages services |
| Root account | All powerful administrator |
