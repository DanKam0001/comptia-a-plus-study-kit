# Exam check: macOS and Linux for Windows People

Cover the answers and try each one out loud first.

**1.** A Mac app has frozen and won't close, no matter how many times the user clicks it. What should the user do?
<details><summary>Answer</summary>Open Force Quit (Option + Command + Esc), select the app and click Force Quit.</details>

**2.** A Mac user wants automatic backups of their files to an external drive. Which built in tool does this?
<details><summary>Answer</summary>Time Machine.</details>

**3.** On Ubuntu Linux, a technician needs to install a program from the command line, which needs administrator rights. Which command does this?
<details><summary>Answer</summary>`sudo apt install <program>`. Apt is the package manager on Ubuntu, and sudo runs the command with root rights.</details>

## More practice (written for this kit)

**4.** A user downloads a `.dmg` file on a Mac. How do they install the app?
<details><summary>Answer</summary>Open the disk image and drag the app into the Applications folder.</details>

**5.** A company wants a stolen Mac's data to be unreadable. Which feature should be on?
<details><summary>Answer</summary>FileVault (full disk encryption).</details>

**6.** Which Linux command is most like Windows Task Manager?
<details><summary>Answer</summary>`top` (a live list of processes). `ps` is a one-time list.</details>

**7.** A file's permissions should let the owner read and write, and everyone else only read. Which `chmod` number?
<details><summary>Answer</summary>`chmod 644`. Owner 6 (read 4 + write 2), group 4, others 4.</details>

**8.** Which Linux file holds the hashed passwords, and who can read it?
<details><summary>Answer</summary>`/etc/shadow`, readable only by root.</details>

**9.** Which Linux command checks a filesystem for errors, like chkdsk on Windows?
<details><summary>Answer</summary>`fsck`.</details>

**10.** Which folder on a Mac holds each person's home folder?
<details><summary>Answer</summary>`/Users`.</details>

**11.** A Fedora technician needs to install software. Which package manager do they use?
<details><summary>Answer</summary>`dnf`. (apt is for Debian and Ubuntu.)</details>
