## Requirements

| Question | Answer |
|---|---|
| Can a 64-bit app run on a 32-bit OS? | No |
| Can a 32-bit app run on a 64-bit Windows? | Usually yes |
| Memory a 32-bit OS can use | About 4 GB |
| Dedicated graphics vs integrated graphics | Dedicated = own card, own VRAM. Integrated = in the CPU, shares system RAM |
| VRAM stands for | Video Random Access Memory |
| External hardware token | A USB key (dongle) that proves you own a license |
| Application requirements checklist | 32/64-bit, graphics, VRAM, RAM, CPU, hardware token, storage, OS compatibility |

## Distribution methods (4)

| Method | One line |
|---|---|
| Physical media | Install from a disc |
| Mountable ISO file | A disc copy in one file, mounted as a virtual drive |
| Downloadable package | Download and run |
| Image deployment | One prepared image copied to many PCs |

| Question | Answer |
|---|---|
