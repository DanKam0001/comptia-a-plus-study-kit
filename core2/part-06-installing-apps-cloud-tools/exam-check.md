# Exam check: Installing Apps and Cloud Productivity Tools

Cover the answers and try each one out loud first.

**1.** A user tries to install a 64-bit program on a PC that is running 32-bit Windows, and it refuses to run. What is the reason?
<details><summary>Answer</summary>A 64-bit program cannot run on a 32-bit version of Windows. (Why: 64-bit programs need a 64-bit operating system. The reverse works, since 32-bit programs usually run fine on 64-bit Windows.)</details>

**2.** A technician needs to install a program from a disc image file, but the laptop has no disc drive. What should they do?
<details><summary>Answer</summary>Mount the ISO file as a virtual drive. (Why: an ISO file is a copy of a disc. Windows can mount it as a virtual drive, so no real disc or disc drive is needed.)</details>

**3.** A new employee can sign in to the company's cloud apps, but the spreadsheet app says they have no license. What does the administrator need to do?
<details><summary>Answer</summary>Assign a license to their account. (Why: cloud apps are paid for per user, so the administrator must assign a license to the person's account.)</details>

## More practice (written for this kit)

**4.** An IT team must put the same Windows and apps setup on 40 identical new PCs. Which distribution method fits best?
<details><summary>Answer</summary>Image deployment: one prepared image copied to all the PCs.</details>

**5.** A video editing program is slow and its preview is choppy on a PC that uses integrated graphics. Which hardware change helps most?
<details><summary>Answer</summary>Add a dedicated graphics card with its own VRAM, so the editor stops sharing system RAM.</details>

**6.** A professional design program will not start, although the PC meets every requirement. It worked yesterday with a small USB key plugged in. What is missing?
<details><summary>Answer</summary>The external hardware token (dongle) is not plugged in.</details>

**7.** Name the four areas a company should think about when judging the impact of a new application.
<details><summary>Answer</summary>Device, network, operation, and business.</details>

**8.** A user's account and password are the same in the office and in the cloud because the two are kept matched automatically. What is this called?
<details><summary>Answer</summary>Identity synchronization.</details>
