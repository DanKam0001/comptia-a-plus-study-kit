## Task Manager

| Question | Answer |
|---|---|
| Open Task Manager with the keyboard | Ctrl + Shift + Esc |
| The five Task Manager tabs on the objectives | Processes, Performance, Users, Startup, Services |
| Close a frozen program from Task Manager | Processes tab, select it, End task |
| Where to stop a program launching at sign in | Task Manager, Startup tab |

## Facts

| Question | Answer |
|---|---|
| Event Viewer's three main logs | Application, System, Security |
| Which snap-ins are missing from Windows Home | Group Policy Editor and Local Users and Groups |
| Yellow triangle in Device Manager means | A driver problem |
| Defragment an SSD? | No. Windows optimizes it (TRIM) instead |
| Before editing the registry | Back it up (File, Export) |
| Sleep vs hibernate | Sleep keeps work in RAM, wakes fast. Hibernate saves to the drive and powers off fully |
| Default power plan | Balanced |
| The three standard power plans | Balanced, Power saver, High performance |
| Fast startup does | A shutdown saves the kernel to disk so the next boot is quicker |
| USB selective suspend does | Powers down idle USB ports to save energy |
| Show file extensions: where | File Explorer Options, View tab, untick "Hide extensions for known file types" |
| Open the Settings app | Windows key + I |
| Settings categories on the objectives | System, Devices, Network and Internet, Personalization, Apps, Accounts, Time and Language, Gaming, Ease of Access, Privacy, Update and Security |
