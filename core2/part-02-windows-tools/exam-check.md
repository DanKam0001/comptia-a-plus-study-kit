# Exam check: Windows Tools

Cover the answers and try each one out loud first.

**1.** A computer has become very slow, and the user wants to see which program is using all the memory. Which tool should you open?
<details><summary>Answer</summary>Task Manager. Its Processes tab shows memory use per program, and End task closes the one causing trouble.</details>

**2.** A program keeps crashing, and you need to find the error message that Windows recorded about it. Which tool shows it?
<details><summary>Answer</summary>Event Viewer (eventvwr.msc). The Application log records program errors.</details>

**3.** A new hard drive is installed, but it doesn't show up in File Explorer. Which tool do you use to initialize it and create a volume?
<details><summary>Answer</summary>Disk Management (diskmgmt.msc). A blank drive needs to be initialized, given a volume, formatted and given a drive letter.</details>

## More practice (written for this kit)

**4.** A technician opens Device Manager and sees a yellow triangle beside the network adapter. What does it mean?
<details><summary>Answer</summary>The device has a driver problem. Update, roll back or reinstall the driver.</details>

**5.** A company wants a script to run every night at 2 a.m. Which tool schedules it?
<details><summary>Answer</summary>Task Scheduler (taskschd.msc).</details>

**6.** A technician can't find Group Policy Editor on a customer's PC. What is the most likely reason?
<details><summary>Answer</summary>The PC runs Windows Home, which doesn't include gpedit.msc.</details>

**7.** Which tool gives a detailed live view of which process is using the disk and the network?
<details><summary>Answer</summary>Resource Monitor (resmon.exe).</details>

**8.** What should you do before changing anything in Registry Editor?
<details><summary>Answer</summary>Back up the registry with File, Export. One wrong change can break Windows.</details>

**9.** A user wants the laptop to carry on running when the lid is closed. Where do you set this?
<details><summary>Answer</summary>Power Options, "Choose what closing the lid does".</details>

**10.** What is the difference between sleep and hibernate?
<details><summary>Answer</summary>Sleep keeps your work in RAM and wakes in seconds. Hibernate saves it to the drive and powers off fully.</details>
