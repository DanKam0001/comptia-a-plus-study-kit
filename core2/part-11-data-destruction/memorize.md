# Memorise list: Data Destruction and Disposal (Core 2, Part 11)

Understand the video first, then learn these cold. They're the facts a scenario question assumes you already know.
Flashcards: [`flashcards/core2_part11.csv`](../../flashcards/core2_part11.csv) (import into Anki or any flashcard app).

| Question | Answer |
|---|---|
| Four physical destruction methods | Drilling, shredding, degaussing, incineration |
| Does deleting a file remove the data? | No. It removes the index entry only |
| Does a standard format (or quick format) remove data? | No. Data stays recoverable |
| Low-level format does | Overwrites every sector (usually zeros) |
| Erasing / wiping does | Overwrites the whole drive with zeros or random data |
| Which methods keep the drive usable? | Wiping, low-level format |
| Degaussing works on | Magnetic media only: hard drives, tape |
| Does degaussing work on an SSD? | No. SSDs use flash chips |
| Drilling goes through what part? | The platters |
| Which method is done by a licensed facility? | Incineration |
| Proof an outside vendor destroyed the drives | Certificate of destruction (or recycling) |
| What should a certificate list? | Drives (serial numbers), date, method |
| Safe way to clear an SSD for reuse | Maker's secure erase tool |
| Wiping is for | Drives that will be reused, sold or donated |
| Destruction is for | Drives never reused, failed drives, or very sensitive data |
| Where do old electronics go? | An approved e-waste recycler |
