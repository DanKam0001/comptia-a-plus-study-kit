# Exam check: Documentation, Change Management, Backup and Recovery

Cover the answers and try each one out loud first.

**1.** A technician fixes a customer's PC, but writes nothing down. A week later the same problem comes back, and nobody knows what was already tried. What should the technician have done?
<details><summary>Answer</summary>Recorded the issue, progress notes and resolution in the ticket. Good notes let the next technician see what was tried and what fixed it.</details>

**2.** A company wants to install a risky update on its main server in the middle of the working day. What should happen first?
<details><summary>Answer</summary>Submit a change request with a risk analysis and a rollback plan, and get approval from the change board. The work belongs in a maintenance window.</details>

**3.** A drive dies on Thursday. The backups are one full backup on Sunday, and an incremental backup every night. What do you restore?
<details><summary>Answer</summary>Sunday's full backup, then each incremental backup since (Monday, Tuesday and Wednesday). Incrementals only hold changes since the last backup.</details>

## More practice (written for this kit)

**4.** Which document gives step by step instructions for a routine job, such as a custom software package installation?
<details><summary>Answer</summary>A standard operating procedure (SOP).</details>

**5.** A company has a promise from an outside vendor to fix faults within four hours. What is that document called?
<details><summary>Answer</summary>An external (third-party) service-level agreement (SLA).</details>

**6.** A server has failed and must be fixed at once. There is no time for the normal approval cycle. Which change type is this?
<details><summary>Answer</summary>An emergency change. It is still documented.</details>

**7.** The nightly backups are differential, with a full backup on Sunday. A drive fails on Thursday. What do you restore?
<details><summary>Answer</summary>Sunday's full backup and Wednesday's differential only.</details>

**8.** What does the 3-2-1 backup rule say?
<details><summary>Answer</summary>Keep 3 copies of your data, on 2 different types of media, with 1 copy offsite.</details>

**9.** Which backup is built on the backup server from an old full backup plus later changes, without reading the PC again?
<details><summary>Answer</summary>A synthetic full backup.</details>

**10.** A user leaves the company. Which checklist makes sure their access is removed and their laptop is collected?
<details><summary>Answer</summary>The user off-boarding checklist.</details>
