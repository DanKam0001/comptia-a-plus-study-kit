# Memorise list: Troubleshooting Mobile OS, Apps and PC Security Issues (Core 2, Part 13)

Understand the video first, then learn these cold. They're the facts a scenario question assumes you already know.
Flashcards: [`flashcards/core2_part13.csv`](../../flashcards/core2_part13.csv) (import into Anki or any flashcard app).

| Question | Answer |
|---|---|
| App won't launch or crashes: easy fix ladder | Force close, restart phone, free storage, update, clear cache, reinstall |
| OS update fails: usual causes | Low storage, low battery, poor connection |
| Phone battery drains fast: first check | Battery usage by app, then brightness and background apps |
| Bluetooth won't connect: fix | On, close range, forget the device and pair again |
| Wi-Fi won't connect on a phone: fix | Airplane mode off, forget the network and rejoin |
| NFC range | A few centimetres. Remove thick cases |
| Screen won't rotate: fix | Turn off rotation lock |
| Installing an app from outside the official store | Sideloading |
| Rooting is for which OS? | Android |
| Jailbreaking is for which OS? | iPhone (iOS) |
| App that imitates a real one | Application spoofing |
| Developer mode: should it be on? | Off unless needed |
| Nine mobile security symptoms | High network traffic, slow response, data-usage warning, limited internet, no internet, lots of ads, fake security warnings, odd app behaviour, leaked data |
| False antivirus alerts are | Rogue antivirus (scareware) |
| Files renamed or can't be opened | Ransomware or other malware |
| Redirection: what to check | Extensions, proxy, DNS (and hosts file) |
| Certificate warning: what to do | Don't proceed. Also check the PC clock |
| Update failures on an infected PC | Malware blocking updates |
| Where are malware removal steps? | Core 2 Part 9 (investigate, quarantine, remediate, scan, educate...) |
