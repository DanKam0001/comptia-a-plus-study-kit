# Exam check: Security Measures, Wireless Security and Authentication

Cover the answers and try each one out loud first.

**1.** People keep following employees through the front door without using a badge. Which physical security control best stops this?
<details><summary>Answer</summary>An access control vestibule. (Why: it is a small two-door room that lets only one person through at a time, which stops tailgating.)</details>

**2.** A small office wants the strongest Wi-Fi security its new router offers. Which should it choose?
<details><summary>Answer</summary>WPA3. (Why: it is the newest and strongest. TKIP is old and weak, and Kerberos is for sign-in, not Wi-Fi encryption.)</details>

**3.** A stolen password let an attacker into an employee's account. What should the company add so a password alone is not enough?
<details><summary>Answer</summary>Multifactor authentication. (Why: it asks for a second proof, like a code from an app, so a stolen password alone cannot open the account.)</details>

## More practice (written for this kit)

**4.** A company wants staff to sign in once and reach email, chat and the HR system without typing a password again. What is this called?
<details><summary>Answer</summary>Single sign-on (SSO), often using SAML.</details>

**5.** A contractor needs administrator rights for one afternoon only. Which approach fits?
<details><summary>Answer</summary>Just-in-time access, managed with privileged access management (PAM).</details>

**6.** A company wants one central server to control and log which administrators can sign in to its routers and switches. Which authentication system is mainly used for this?
<details><summary>Answer</summary>TACACS+. (RADIUS is mainly for network access such as Wi-Fi and VPN.)</details>

**7.** Which Wi-Fi encryption method is old, weak and should be avoided?
<details><summary>Answer</summary>TKIP.</details>

**8.** A server room needs a way to stop someone walking off with a rack server. Which control is aimed at this?
<details><summary>Answer</summary>Equipment locks (locked racks and cabinets).</details>

**9.** A user's sign-in needs a password and then a code that changes every 30 seconds. What is the code type called?
<details><summary>Answer</summary>TOTP, a time-based one-time password.</details>
