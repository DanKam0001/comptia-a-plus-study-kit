## Remote access

| Question | Answer |
|---|---|
| RDP port | 3389 |
| SSH port | 22 |
| VNC port | 5900 |
| WinRM ports | 5985 (HTTP), 5986 (HTTPS) |
| Secure command line to a remote server | SSH |
| Remote Windows desktop | RDP |
| Encrypted tunnel into a company network | VPN |
| One console for many client computers | RMM (remote monitoring and management) |
| SPICE is used for | Remote display of virtual machines |
| WinRM does | Runs commands on remote Windows computers |
| Safest way to offer RDP | Behind a VPN, never open to the internet |

## Script risks and AI

| Question | Answer |
|---|---|
| Three risks of scripts | Unintentionally introducing malware, inadvertently changing system settings, crashes from mishandling resources |
| Seven use cases of scripting | Basic automation, restarting machines, remapping network drives, installing applications, automated backups, gathering information, initiating updates |
| AI that confidently makes things up | Hallucination |
| Unfair leanings in AI output | Bias |
| Three AI policy and data points | Appropriate use, plagiarism, data privacy |
| Public vs private AI | Public is outside your control. Private runs inside the company |
| Never paste into a public AI | Private or customer data |
