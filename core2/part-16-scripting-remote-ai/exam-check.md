# Exam check: Scripting, Remote Access and AI

Cover the answers and try each one out loud first.

**1.** A technician has to remap the same network drive on 200 computers. What is the best approach?
<details><summary>Answer</summary>Write one script and run it on every computer. Remapping drives is a classic scripting job.</details>

**2.** A technician needs to securely manage a Linux server in another city, using only a command line. Which tool should they use?
<details><summary>Answer</summary>SSH (Secure Shell). It gives an encrypted command line. RDP and VNC are graphical tools.</details>

**3.** An employee pastes customers' private data into a public AI chatbot to write a summary. What is the main risk?
<details><summary>Answer</summary>The private data could be exposed or stored outside the company. A public AI is outside the company's control.</details>

## More practice (written for this kit)

**4.** Which file extension is a PowerShell script?
<details><summary>Answer</summary>`.ps1`</details>

**5.** Which file extension is a shell script used on Linux and macOS?
<details><summary>Answer</summary>`.sh`</details>

**6.** A support company wants to watch and fix hundreds of client PCs from one console. What kind of software is this?
<details><summary>Answer</summary>RMM (remote monitoring and management).</details>

**7.** An AI assistant cites a book that does not exist. What is this called?
<details><summary>Answer</summary>A hallucination.</details>

**8.** A script downloaded from a forum changes a user's settings without asking. Which scripting risk is this?
<details><summary>Answer</summary>Inadvertently changing system settings (running an untrusted script).</details>

**9.** What is the safest way to let staff use RDP from home?
<details><summary>Answer</summary>Put RDP behind a VPN, rather than opening it to the internet.</details>

**10.** Which protocol runs commands on remote Windows computers using ports 5985 and 5986?
<details><summary>Answer</summary>WinRM (Windows Remote Management).</details>
