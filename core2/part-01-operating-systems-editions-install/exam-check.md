# Exam check: Operating Systems, Windows Editions and Installing Them

Cover the answers and try each one out loud first.

**1.** A shop needs to set up fifty identical laptops, and installing Windows on each one by hand would take days. Which approach is best?
<details><summary>Answer</summary>Image deployment.<br><br><em>Why:</em> it copies one ready-made setup, with the apps already installed, onto every machine. It is far faster than installing by hand.</details>

**2.** A user with Windows 11 Home wants BitLocker drive encryption and needs to join the company domain. What is needed?
<details><summary>Answer</summary>Upgrade to Windows 11 Pro.<br><br><em>Why:</em> Home has no BitLocker and can't join a domain. Pro and above can.</details>

**3.** A technician installs a new 4 TB drive, but only 2 TB shows up. What is the most likely cause?
<details><summary>Answer</summary>The drive was initialized as MBR instead of GPT.<br><br><em>Why:</em> MBR can only use 2 TB of a drive. GPT uses the whole drive.</details>

## More practice (written for this kit)

**4.** Which file system suits a USB drive that holds files over 4 GB and is shared between Windows and a Mac?
<details><summary>Answer</summary>exFAT.</details>

**5.** Which install type keeps your files and apps but replaces the Windows system files to fix problems?
<details><summary>Answer</summary>A repair installation.</details>

**6.** During a Windows install, setup shows no drives, but the PC has a RAID controller. What do you do?
<details><summary>Answer</summary>Load the third-party storage driver during setup.</details>

**7.** A user wants to Remote Desktop into their Windows 11 Home PC from another PC. What is the problem?
<details><summary>Answer</summary>Home can connect out with Remote Desktop but cannot be connected to. It needs Pro or above.</details>

**8.** What does end-of-life mean for an operating system?
<details><summary>Answer</summary>The vendor stops providing updates and support, including security updates.</details>

**9.** Name the two firmware features a PC must have for Windows 11.
<details><summary>Answer</summary>TPM 2.0 and UEFI with Secure Boot.</details>

**10.** Which file systems does Linux commonly use?
<details><summary>Answer</summary>ext4 and XFS.</details>

**11.** What is the maximum RAM on Windows 11 Home, and on Pro?
<details><summary>Answer</summary>128 GB on Home, 2 TB on Pro.</details>
